# QVibe homepage

Production-quality visual prototype of the QVibe homepage, built as a dependency-free static site.

## Run locally

Open `index.html` directly, or serve the folder with any static server, for example:

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Scope

Complete V1: Home, Kondapalli, Kalamkari, Mangalagiri, Our Vision and Connect.

The site is a vision-and-research-stage presentation prototype. It contains no ecommerce or current operational claims.
